# Basic-calculator
Implemented addition, subtraction, multiplication, and division with an interactive and responsive interface.


🚀 Features
Addition, subtraction, multiplication, and division
Simple and interactive user interface
Responsive design
Clear button to reset calculations
Easy-to-use calculator layout

🛠️ Technologies Used
HTML – Structure of the calculator
CSS – Styling and layout
JavaScript – Calculation logic and interactivity

This project was created to practice front-end web development and improve my skills in HTML, CSS, and JavaScript.
